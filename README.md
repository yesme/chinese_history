# 中国历史研读

> 有故事可追，有人物可品，有史事可考，有兴亡可思。

一套面向个人研读与家庭共读的中国历史阅读框架：以七大书目体系整理藏书，以分阶段路径安排阅读，在故事、史事、地理、制度与原典之间逐步深入。

## 七大书目体系

| 体系 | 定位 |
| --- | --- |
| 国民通识 | 以历史故事、神话传说和文明图鉴建立人物、典故与时代轮廓 |
| 演义说史 | 通过古典演义和历朝通俗演义进入章回叙事与人物故事 |
| 名家细说 | 以断代讲述补充制度、掌故与史事辨析 |
| 现代读史 | 按时代组织叙事通读、专题研读与历史小说 |
| 地理战史 | 结合地图、地形、交通与粮道理解历史局势和战争选择 |
| 顶层总纲 | 从政治制度、疆域政区、思想社会与文明交流观察长时段变化 |
| 史籍原典 | 回到先秦典籍、纪传、编年、本末与史论，追索材料与史家判断 |

## 阅读路径

### 成人进阶

由故事入史，依次经过断代通读、循图观势、察制观变与循文索源。已有阅读基础者可以从熟悉的时代切入，不必机械地从第一阶开始。

### 六种常用读法

- **循时入史**：连续读通一个时代。
- **含英咀华**：细读叙事、对白与文章章法。
- **知人论世**：理解人物的处境、选择与代价。
- **循图观势**：把战争与政局放回地理条件中。
- **察制观变**：从人物事件进入制度运行。
- **文史相参**：比较史籍记载、文学加工与民间叙事。

### 孩子成长

从小学阶段的亲子故事共读起步，逐步过渡到独立阅读、断代对读、中英文学术衔接与专题表达。主文档另附一份从小学一年级开始的十二周共读安排，可按兴趣与阅读能力灵活调整。

## 使用建议

1. 先浏览主文档的“七大体系总览”，确定当前需要的是通识、断代、专题还是原典。
2. 每次选择一部主读作品，再按问题搭配地图、断代史或原典，不必同时铺开所有书目。
3. 阅读时区分史实记载、作者解释与文学虚构；遇到疑问，记录出处并保留待考问题。
4. 家庭共读以兴趣和持续表达为主，可根据孩子的理解程度调整进度。
